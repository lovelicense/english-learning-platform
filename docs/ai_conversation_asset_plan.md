# AI 대화 자산화 설계안

## 목적
- AI와의 대화를 단순 채팅 기능이 아니라 `개인 언어 자산 수집 채널`로 확장
- 영어 AI 대화는 `영어 표현 자산화 + 다이얼로그 연습 재사용`
- 한국어 AI 대화는 `한국어 원천 데이터 수집` 후 기존 `영어 표현 생성` 파이프라인으로 연결


## 기능 트랙 정의

### 1. 영어 AI 대화 트랙 (`A + B + C`)
영어로 AI와 대화하고, 그 대화를 영어 학습 자산으로 재활용하는 트랙

- A. AI 대화 기록 저장
- B. 대화 -> 다이얼로그 연습 변환
- C. 내 영어 표현 자산 저장

흐름:

```text
영어 AI 대화
-> 대화 세션 저장
-> 내 영어 발화 교정 / 자연형 생성
-> 내 영어 표현 자산 저장
-> 대화를 다이얼로그 연습 세트로 변환
-> 기존 말하기 테스트 / 오늘의 복습과 통합
```

핵심 특징:
- `user turn` 뿐 아니라 `ai turn`도 함께 저장
- 저장된 대화는 나중에 그대로 다시 연습 가능
- 내가 말한 영어 표현은 기존 `Expression` 풀에 합류


### 2. 한국어 AI 대화 트랙 (`D`)
AI와 한국어로 대화하며 한국어 원천 데이터를 수집하는 트랙

- D. AI와 한국어 대화 -> 한국어 자산 수집

흐름:

```text
한국어 AI 대화
-> 한국어 대화 세션 저장
-> 내 한국어 발화를 한국어 원천 자산으로 저장
-> 이후 흐름은 녹음파일 업로드 후 STT 이후와 동일
-> 영어 표현 생성
-> TTS / 테스트 / 복습으로 연결
```

핵심 특징:
- 개념적으로 `파일 업로드`, `브라우저 녹음`과 같은 레벨의 입력 채널
- 차이는 음성 STT가 아니라 `AI 채팅/대화 텍스트`에서 한국어 원천 문장을 수집한다는 점


## 기존 시스템과의 관계

### 기존 수집 채널
- 파일 업로드
- 브라우저 녹음
- 향후 모바일 녹음

### 추가될 수집 채널
- 영어 AI 대화
- 한국어 AI 대화

정리:
- 영어 AI 대화는 `영어 자산 수집 채널`
- 한국어 AI 대화는 `한국어 원천 데이터 수집 채널`


## 제품 구조에서의 위치

### 영어 AI 대화 트랙
- 결과물이 `영어 표현 자산`과 `다이얼로그 연습 세트`
- 기존 `Expression`, `PracticeLog`, `Review`와 직접 연결

### 한국어 AI 대화 트랙
- 결과물이 `한국어 원천 자산`
- 기존 `SavedSentence`, 필요 시 `Expression 생성`, `TTS`, `Practice` 흐름으로 연결


## 데이터 모델 제안

기존 모델을 최대한 재사용하고, AI 대화 세션 계층만 새로 추가하는 방향이 적합

### 신규 모델 1. `ConversationSession`
AI와의 대화 세션 단위

추천 필드:
- `id`
- `userId`
- `mode`
  - `ENGLISH_AI`
  - `KOREAN_AI`
- `title`
- `topic`
- `scenario`
- `goal`
- `source`
  - `ai_conversation`
- `summary`
- `status`
  - `ACTIVE`
  - `COMPLETED`
  - `ARCHIVED`
- `createdAt`
- `updatedAt`
- `completedAt`

역할:
- 대화 기록 묶음
- 이후 다이얼로그 연습 변환의 기준 세션


### 신규 모델 2. `ConversationTurn`
세션 내 발화 한 턴

추천 필드:
- `id`
- `sessionId`
- `turnIndex`
- `speaker`
  - `USER`
  - `AI`
- `language`
  - `EN`
  - `KO`
  - `MIXED`
- `originalText`
- `correctedText`
- `naturalText`
- `correctionNote`
- `errorTags` (`Json` or string array)
- `intent`
- `contextNote`
- `audioKey` optional
- `ttsKey` optional
- `dialogueAudioKey` optional
- `isAssetCandidate`
- `assetSavedAt`
- `createdAt`

역할:
- 영어 트랙에서는 교정과 자산화의 기본 단위
- 한국어 트랙에서는 원천 문장 수집의 기본 단위
- `dialogueAudioKey`는 다이얼로그 연습으로 확정된 AI 대사의 재생 음성 캐시 용도


### 신규 모델 3. `DialoguePracticeSet`
저장된 대화를 반복 연습용 세트로 변환한 결과

추천 필드:
- `id`
- `userId`
- `conversationSessionId`
- `title`
- `topic`
- `scenario`
- `source`
  - `ai_conversation`
- `createdAt`
- `updatedAt`


### 신규 모델 4. `DialoguePracticeTurn`
다이얼로그 연습의 실제 문제 단위

추천 필드:
- `id`
- `practiceSetId`
- `sequence`
- `aiPrompt`
- `expectedUserAnswer`
- `expectedUserAnswerAlt`
- `hint`
- `explanation`
- `expressionId` optional
- `sourceConversationTurnId`
- `createdAt`

역할:
- 나중에 `AI가 같은 질문 -> 내가 답 -> 채점 -> 다음 턴` 흐름으로 재사용


## 기존 모델 재사용 방안

### 영어 AI 대화 -> `Expression`
영어 AI 대화에서 `USER`가 말한 영어 발화는 가치가 있으면 기존 `Expression`으로 저장

저장 기준 예시:
- correctedText 기준으로 저장
- originalText는 메모 또는 별도 source 필드로 보존
- `note` 또는 `userMemo`에 교정 포인트 일부 반영 가능

추가 추천 필드:
- `sourceType`
  - `UTTERANCE`
  - `SAVED_SENTENCE`
  - `AI_ENGLISH_CONVERSATION`
- `conversationTurnId` optional

의도:
- 기존 빠른 입력 / 녹음 / AI 영어 대화에서 나온 표현을 한 풀로 관리


### 한국어 AI 대화 -> `SavedSentence`
한국어 AI 대화에서 `USER`가 말한 한국어 발화는 `SavedSentence`로 저장

저장 방식:
- `koreanText`: 사용자 발화
- `contextNote`: 대화 맥락 또는 AI 질문
- `situation`, `analysisIntent`, `analysisSummary`: 세션 메타나 LLM 분석 결과 반영

추가 추천 필드:
- `sourceType`
  - `MANUAL`
  - `RECORDING`
  - `AI_KOREAN_CONVERSATION`
- `conversationTurnId` optional

의도:
- 녹음 업로드 후 STT로 얻은 한국어 데이터와 같은 수준의 원천 데이터로 편입


## 트랙별 상세 플로우

### 영어 AI 대화 트랙 상세

#### A. AI 대화 기록 저장
- 사용자와 AI의 모든 turn 저장
- 대화 메타데이터 저장
  - 주제
  - 상황
  - 학습 목표
  - 시작/종료 시각

#### B. 대화 -> 다이얼로그 연습 변환
- `AI turn`은 고정 프롬프트로 사용
- 그 다음 `USER turn`의 corrected/natural 문장을 기대 답안으로 사용
- 원하는 경우 일부 턴만 선택해서 연습 세트 생성 가능
- 이 시점에만 다이얼로그 재현용 데이터를 서버에 확정 저장
- AI 대사의 음성도 이 시점에 필요한 turn만 TTS 생성 후 저장

예시:

```text
AI: What did you do yesterday?
USER original: I go hospital yesterday.
USER corrected: I went to the hospital yesterday.

=> 다이얼로그 연습
Prompt: What did you do yesterday?
Expected answer: I went to the hospital yesterday.
```

저장 정책:
- 대화 중에는 `ConversationSession`, `ConversationTurn`에 텍스트 중심으로만 저장
- `다이얼로그 변환` 버튼을 누를 때 서버에서 아래를 수행
  - `DialoguePracticeSet` 생성
  - 선택된 `DialoguePracticeTurn` 생성
  - 포함된 `AI turn`만 재현용 음성 생성 및 저장
- 즉, AI 대사 음성은 처음 대화할 때 전부 저장하지 않음
- 음성 저장 범위는 실제로 연습 세트에 포함된 turn으로 제한

#### C. 내 영어 표현 자산 저장
- 사용자 영어 turn을 기존 `Expression` 자산으로 저장
- 저장 시 함께 남기면 좋은 정보
  - originalText
  - correctedText
  - naturalText
  - errorTags
  - sourceConversationTurnId
- 저장된 표현은 기존 `말하기 테스트`, `오늘의 복습`, `TTS` 대상에 포함


### 한국어 AI 대화 트랙 상세

#### D. AI와 한국어 대화 -> 한국어 자산 수집
- 사용자 한국어 turn만 선별해서 `SavedSentence`로 저장
- 이후는 기존 흐름과 동일

```text
SavedSentence 저장
-> 영어 표현 생성
-> 영어 TTS 생성
-> 말하기 테스트
-> 오늘의 복습
```

AI 답변은 다음 용도로 별도 보존 가능:
- contextNote 보강
- 대화 요약 생성
- 나중에 한국어 대화 기록 조회

## 대시보드 연결 위치 제안

### 추천 결론
- `영어 AI 대화 트랙`과 `한국어 AI 대화 트랙`은 둘 다 대시보드의 새 상위 섹션 `AI 대화` 아래로 묶는다
- `AI 대화` 섹션 내부에서만 `영어 대화 / 한국어 대화` 2개 탭으로 분리한다

이유:
- 사용자 입장에서는 둘 다 먼저 `AI와 대화하는 기능`으로 인식됨
- 하지만 대화 후 결과물은 다르므로 내부 탭에서 목적을 분리하는 것이 자연스러움
- 영어 AI 대화를 `표현`에, 한국어 AI 대화를 `녹음`에 따로 흩어놓으면 기능 위치가 찢어져 보일 가능성이 큼


### 상단 네비게이션 권장 순서
- `원클릭`
- `녹음`
- `표현`
- `AI 대화`
- `연습`
- `기록`
- `TTS`

배치 의도:
- `녹음`과 `AI 대화`는 둘 다 수집 채널
- `표현`은 자산 관리 영역
- `연습`은 학습 실행 영역
- 따라서 `AI 대화`는 `표현`과 `연습` 사이에 두는 것이 흐름상 가장 자연스러움


### 왜 이 위치가 좋은가

#### 영어 AI 대화 트랙
- 결과물이 `영어 표현 자산`, `다이얼로그 연습 세트`
- 이후 `말하기 테스트`, `오늘의 복습`, `다이얼로그 연습`으로 이어짐
- 따라서 성격상 `표현 생성의 확장 입력 채널`이면서 `연습 준비 채널`

#### 한국어 AI 대화 트랙
- 결과물이 `한국어 원천 자산`
- 이후 `영어 표현 생성 -> TTS -> 테스트 -> 복습`으로 이어짐
- 개념적으로는 `녹음/업로드`와 같은 수집 채널
- 다만 UI는 `녹음` 안이 아니라 `AI 대화` 안의 한국어 탭으로 두는 편이 일관적


### `AI 대화` 내부 2개 탭

#### 1. 영어 AI 대화
- 자유 대화
- 역할극
- AI 응답 방식 선택
  - 텍스트
  - 음성
- 답변 방식 선택
  - 텍스트 입력
  - 음성 입력 후 STT
- 교정 모드 선택
- 대화 저장
- 자산 저장
- 다이얼로그 변환

주요 화면:
- 좌측 또는 상단: 대화 타임라인
- 우측 또는 하단: 교정 / 자연형 / 저장 패널

지원 조합:
- `AI(텍스트) + 답변(텍스트)`
- `AI(텍스트) + 답변(음성 -> STT)`
- `AI(음성) + 답변(텍스트)`
- `AI(음성) + 답변(음성 -> STT)`


#### 2. 한국어 AI 대화
- 한국어로 AI와 대화
- AI 응답 방식 선택
  - 텍스트
  - 음성
- 답변 방식 선택
  - 텍스트 입력
  - 음성 입력 후 STT
- 대화 종료 후 `내 한국어 발화 저장`
- 저장 후 바로 `영어 표현 생성` 버튼 제공

주요 화면:
- 대화 타임라인
- 한국어 자산 후보 목록
- `선택 저장`
- `전체 저장 후 영어 표현 생성`

지원 조합:
- `AI(텍스트) + 답변(텍스트)`
- `AI(텍스트) + 답변(음성 -> STT)`
- `AI(음성) + 답변(텍스트)`
- `AI(음성) + 답변(음성 -> STT)`


### 추가 화면 1. `AI 대화 기록`
- 세션 목록
- 영어 / 한국어 필터
- 주제 / 날짜 / 저장 여부 필터
- 세션 상세 조회


### 추가 화면 2. `다이얼로그 연습`
- AI 대화에서 생성한 연습 세트 목록
- 세트 선택 후 turn 기반 연습
- 채점 후 다음 턴 이동

## 현재 대시보드 기준 연결 방식

### 1. 새 섹션으로 추가
- 현재 `dashboard/page.tsx`에 별도 상위 섹션 `AI 대화`를 추가
- 모바일 상단 칩 네비게이션에도 `AI 대화` 포함

### 2. 기존 섹션과 역할 분리
- `녹음`: 음성/파일 기반 수집
- `표현`: 이미 저장된 영어 자산 관리
- `AI 대화`: AI와의 실시간 상호작용 기반 수집
- `연습`: 테스트/복습/다이얼로그 실행

### 3. 섹션 간 연결 버튼

#### 영어 AI 대화에서
- `표현 저장`
- `다이얼로그 변환`
- `이 표현으로 바로 연습`

#### 한국어 AI 대화에서
- `한국어 자산 저장`
- `영어 표현 생성`
- `저장된 문장 보기`


## 추천 사용자 흐름

### 영어 AI 대화

```text
상단 네비게이션 > AI 대화 > 영어 대화
-> AI와 영어 대화
-> 내 문장 교정 확인
-> 표현 저장
-> 필요하면 다이얼로그 변환
-> 연습에서 재사용
```


### 한국어 AI 대화

```text
상단 네비게이션 > AI 대화 > 한국어 대화
-> AI와 한국어 대화
-> 내 한국어 발화 저장
-> 영어 표현 생성
-> 표현 / TTS / 연습으로 연결
```


## 구현 우선순위

### 1단계: 영어 AI 대화 MVP
목표:
- 영어 AI 대화 기록 저장
- 내 영어 문장 교정
- 표현 자산 저장

범위:
- `ConversationSession`
- `ConversationTurn`
- 영어 AI 대화 UI
- user 영어 turn -> Expression 저장


### 2단계: 다이얼로그 연습 변환
목표:
- 저장 대화를 다시 반복 연습 가능하게 만들기

범위:
- `DialoguePracticeSet`
- `DialoguePracticeTurn`
- 변환 버튼
- 연습 플레이어 연동
- 변환 시 선택된 AI turn의 재현용 음성 서버 저장


### 3단계: 한국어 AI 대화 수집
목표:
- 한국어 AI 대화를 기존 한국어 자산 수집 채널에 편입

범위:
- 한국어 AI 대화 UI
- user 한국어 turn -> SavedSentence 저장
- 기존 영어 표현 생성 흐름 재사용


### 4단계: 자산/복습 통합 강화
목표:
- AI 대화에서 나온 표현도 기존 복습 체계에 자연스럽게 포함

범위:
- review ranking에 AI 출처 표현 포함
- source badge 추가
- export에 AI 대화 출처 포함


## 중요한 설계 원칙

### 1. 영어 AI 대화와 한국어 AI 대화를 섞지 않는다
- 영어 AI 대화는 `영어 자산화`
- 한국어 AI 대화는 `한국어 원천 데이터 수집`

### 2. 기존 핵심 자산 철학을 유지한다
- 한국어 원천 데이터는 여전히 가장 중요한 원천 자산
- 영어 표현은 파생 자산
- 영어 AI 대화는 예외적으로 영어 자체를 원천처럼 수집하는 별도 채널

### 3. 대화 로그와 학습 자산을 분리한다
- 모든 대화가 곧바로 자산이 되지는 않음
- `ConversationSession/Turn`은 로그 계층
- `Expression`, `SavedSentence`, `DialoguePracticeSet`은 자산 계층
- AI 음성도 로그 단계에서 전부 저장하지 않고, 자산 단계인 `다이얼로그 변환 시점`에만 저장

### 4. 기존 학습 흐름과 통합한다
- 새 기능이 별도 섬이 되면 안 됨
- 영어 AI 대화에서 나온 표현은 기존 테스트/복습에 합류
- 한국어 AI 대화에서 나온 문장은 기존 표현 생성 파이프라인으로 연결


## 추천 MVP 한 줄 정의

### 영어 AI 대화 MVP
`영어로 AI와 대화 -> 교정 -> 표현 자산 저장 -> 나중에 같은 대화를 다이얼로그로 반복 연습`

### 한국어 AI 대화 MVP
`한국어로 AI와 대화 -> 내 한국어 발화 저장 -> 기존 영어 표현 생성 흐름으로 연결`


## AI 대사 음성 저장 정책

### 기본 원칙
- AI 대사 음성은 `다이얼로그 변환 버튼 실행 시점`에 서버 저장
- 대화 중에는 AI 응답 텍스트만 우선 저장
- 서버 저장 대상은 `다이얼로그 연습 세트에 포함된 AI turn`만

### 이유
- TTS API 비용 절감
- 불필요한 음성 파일 대량 저장 방지
- 실제로 반복 연습에 쓰일 대사만 고정 음성으로 보존
- 다이얼로그 재현 시 항상 같은 음성으로 안정적으로 반복 가능

### 서버 처리 흐름

```text
영어 AI 대화 종료
-> 사용자 "다이얼로그 변환" 클릭
-> 서버에서 DialoguePracticeSet / Turn 생성
-> 포함된 AI turn에 대해서만 TTS 생성
-> audioKey(dialogueAudioKey) 저장
-> 이후 다이얼로그 연습에서 재사용
```

### 기대 효과
- 저장 비용과 API 사용량을 필요한 시점으로 미룸
- 대화 로그와 연습용 자산의 경계를 명확히 유지
- 재현용 다이얼로그 품질은 유지하면서도 운영 비용을 제어 가능
