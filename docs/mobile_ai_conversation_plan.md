# 모바일 AI 대화 설계안

## 1. 목적
- 웹의 `3. AI 대화` 영역을 모바일에 그대로 옮기지 않고, 모바일 사용 흐름에 맞게 재구성한다.
- 영어 트랙은 `실전 말하기 연습 + 영어 대화 자산 축적 + 다이얼로그 연습 저장`에 집중한다.
- 한국어 트랙은 `빠른 문장 저장`, `대화 녹음`과 나란한 `한국어 표현 수집 채널`로 설계하고, `한국어 자산화 -> 영어 표현 생성 -> 학습` 흐름으로 이어간다.
- 두 트랙 모두 단순 챗 기능이 아니라, 기존 `Expression`, `SavedSentence`, `Practice`, `Review` 흐름으로 다시 합류하는 `수집/연습 채널`로 다룬다.

## 2. 핵심 원칙

### 2-1. 영어 트랙
- AI와 실제로 영어로 말해보는 연습 채널
- 내 영어 답변을 교정하고 자산으로 저장
- 좋은 대화를 다이얼로그 연습 세트로 저장
- 대화 자체보다 `연습 -> 저장 -> 재연습` 루프가 중요

### 2-2. 한국어 트랙
- AI와 한국어로 대화하며 내가 실제로 쓰는 문장을 끌어내는 수집 채널
- 빠른 문장 저장, 대화 녹음과 같은 레벨의 원천 데이터 수집 경로
- 대화는 `문장 채집 수단`, 핵심은 `문장 저장 -> 영어 표현 생성 -> 학습 연결`

### 2-3. 모바일 공통 원칙
- 채팅 화면 중심으로 설계
- 관리 기능은 접고, 현재 대화와 저장 액션을 우선 노출
- 세션/문맥 설정은 `새 대화 시작` 시점에만 보여준다
- 턴별 액션은 최소 개수만 남긴다

## 3. 기존 모바일 기능과의 관계

### 3-1. 영어 트랙의 위치
- 기존 `Expression Practice`, `Reviews`보다 앞단의 `실전 생성 채널`
- 사용자가 실제로 말해본 영어를 교정받고, 좋은 답변을 표현 자산으로 저장하는 흐름
- 세션 단위로는 `다이얼로그 연습` 저장까지 이어져야 한다

흐름:

```text
AI와 영어 대화
-> 내 영어 답변 교정
-> 좋은 답변 저장
-> 표현 자산 합류
-> 표현 연습 / 오늘의 복습
-> 세션은 다이얼로그 연습 세트로도 저장
```

### 3-2. 한국어 트랙의 위치
- 기존 `빠른 문장 저장`, `대화 녹음`과 같은 레벨의 `한국어 수집 채널`
- 대화는 문장을 자연스럽게 끌어내는 인터페이스이고, 핵심은 개별 턴 자산화다
- 세션 전체보다 `사용자 턴 하나를 저장 후 영어 표현 생성`하는 속도가 더 중요하다

흐름:

```text
AI와 한국어 대화
-> 내가 실제로 쓰는 한국어 문장 수집
-> 사용자 턴 저장
-> 영어 표현 생성
-> TTS / 표현 연습 / 오늘의 복습으로 연결
```

### 3-3. Home에서의 역할
- `Home`은 가장 빠른 진입 허브로 유지
- `Quick Save`, `Record`, `AI Conversation`을 나란한 3대 입력 채널로 둔다
- 실제 입력과 세션 관리는 전용 화면으로 분리해 `Home` 자체는 무겁게 만들지 않는다

## 4. 웹 기능을 모바일로 해석한 구조

웹 AI 대화 영역은 실제로 아래 4개 기능 묶음으로 나뉜다.

1. 세션 시작 / 제목 / 문맥 설정
2. 대화 입력/응답
3. 턴 저장 액션
4. 세션 후속 자산화

모바일에서는 이 4개를 한 화면에 다 넣지 않고 아래 3단 구조로 나눈다.

1. `AI Conversation Home`
2. `Conversation Session`
3. `New Conversation Setup`

## 5. 모바일 정보 구조

### 5-1. AI Conversation Home
- 진입 위치:
  - `Home` 탭에 `AI Conversation` 카드
  - 1차는 전용 화면, 사용량이 커지면 추후 주요 탭으로 승격 검토
- 구성:
  - 트랙 선택 카드 2개
    - `영어 연습 시작`
    - `한국어 수집 시작`
  - 트랙 설명 1줄
    - 영어: `AI와 영어로 실제로 말해보고, 좋은 답변은 표현 자산으로 저장`
    - 한국어: `AI와 대화하며 내가 실제로 쓰는 한국어 문장을 모아 영어 학습으로 연결`
  - 최근 세션 리스트
    - 영어 세션 최근 3~5개
    - 한국어 세션 최근 3~5개
  - `새 대화 시작`

### 5-2. New Conversation Setup
- 영어 트랙에서 먼저 중요
- 필드:
  - 나의 역할
  - AI 역할
  - 대화 주제
  - 상황 설명
  - AI 응답 방식: 텍스트 / 음성
  - 내 답변 방식: 텍스트 / 음성(STT)
- 한국어 트랙은 초기에 간소화 가능
  - AI 응답 방식
  - 내 답변 방식
  - 필요 시 주제만

### 5-3. Conversation Session
- 공통 채팅 화면
- 상단:
  - 트랙 이름
  - 세션 제목
  - 현재 모드 요약 배지
- 본문:
  - 채팅 턴 리스트
  - AI / 나 구분
  - 음성 턴이면 TTS 또는 오디오 재생
- 하단 입력:
  - 텍스트 입력 또는 음성 입력(STT)
- 턴별 액션:
  - 영어 트랙: `영어 표현 생성`
  - 한국어 트랙: `저장 후 영어 표현 생성`

## 6. 트랙별 UX 차이

### 6-1. 영어 연습 트랙
- 목표: 영어로 실제로 말해보기
- 강조 요소:
  - AI와 영어로 몇 턴 이상 이어가기
  - 내 답변의 교정 결과 확인
  - 좋은 답변을 표현 자산으로 저장
  - 세션 전체를 다이얼로그 연습으로 변환
- 턴 카드 액션:
  - `영어 표현 생성`
  - 교정 / 자연형 / 의미 설명 보기
- 세션 카드 액션:
  - `다이얼로그 연습으로 저장`

### 6-2. 한국어 수집 트랙
- 목표: 내가 실제로 쓰는 한국어 문장 수집
- 강조 요소:
  - 짧고 빠르게 답변하기
  - 문장별 저장 및 영어 표현 생성
  - 수집 채널로서의 일관성 유지
- 턴 카드 액션:
  - `저장 후 영어 표현 생성`
- 세션 수준 액션은 최소화
  - 다이얼로그 저장보다 문장 자산화가 우선

## 7. 화면별 구성안

### Screen A. AI Conversation Home
- 헤더:
  - `AI Conversation`
  - `영어 연습` / `한국어 수집` 설명
- 섹션:
  - `영어 연습 트랙`
  - `한국어 수집 트랙`
  - `최근 세션`
- 빠른 액션:
  - `영어 대화 시작`
  - `한국어 대화 시작`

### Screen B. New Conversation Setup
- 영어 트랙 중심
- 카드 1:
  - 역할 / 상대 역할
- 카드 2:
  - 주제 / 상황
- 카드 3:
  - AI 응답 방식
  - 내 답변 방식
- 버튼:
  - `대화 시작`

### Screen C. Conversation Session
- 상단:
  - 세션 제목
  - 모드 배지
  - 트랙 배지
- 대화 영역:
  - AI 턴
  - 사용자 턴
  - 교정 / 자연형 / 의미 설명
- 하단:
  - 텍스트 입력창 또는 음성 녹음 버튼
  - `AI에게 보내기`
- 턴 액션:
  - 영어 트랙: `영어 표현 생성`
  - 한국어 트랙: `저장 후 영어 표현 생성`

## 8. 턴 액션과 세션 액션 설계

### 8-1. 영어 트랙 턴 액션
- 기본:
  - `영어 표현 생성`
- 확장:
  - `교정 보기`
  - `자연형 보기`
  - `뜻 보기`
- 세션 액션:
  - `다이얼로그 연습으로 저장`

### 8-2. 한국어 트랙 턴 액션
- 기본:
  - `저장 후 영어 표현 생성`
- 확장:
  - `맥락 메모 포함 저장`
  - `관련 인물 연결`
- 세션 액션:
  - 1차 MVP에서는 약하게 둔다
  - 우선순위는 `최근 세션 이어서`와 `턴 저장`이 더 높다

### 8-3. 웹 옵션을 모바일에서 어떻게 줄일지
- `AI 영문 표시`는 `AI 응답 방식 = AI 음성`일 때만 노출
- 세션 제목 수정, 역할/상황 편집은 채팅 화면 상단에서 바로 다 열지 않고 `세션 설정` 진입으로 숨긴다
- 턴별 보조 정보는 접기/펼치기 구조로 두고, 기본 화면은 대화와 저장 액션 중심으로 유지한다

## 9. 모바일 MVP 우선순위

### Phase 1. 텍스트 대화 MVP
1. AI Conversation Home
2. 영어 / 한국어 트랙 전환
3. 텍스트 입력
4. AI 텍스트 응답
5. 세션 생성 / 최근 세션 이어보기
6. 턴 저장 액션
   - 영어: `영어 표현 생성`
   - 한국어: `저장 후 영어 표현 생성`

### Phase 2. 음성 대화 MVP
1. 내 답변 음성 입력(STT)
2. AI 음성 응답
3. 영어 트랙의 `AI 영문 표시` 옵션
4. 음성 재생 UI 정리

### Phase 3. 자산화 확장
1. 영어 트랙 `다이얼로그 연습으로 저장`
2. 세션 제목 수정
3. 역할 / 상황 설정 저장
4. 최근 세션 목록 강화

## 10. API 대응 맵

웹이 쓰는 기존 API를 모바일에서도 그대로 재사용하는 방향

- 세션 목록:
  - `GET /ai-conversations/sessions?mode=...`
- 세션 상세:
  - `GET /ai-conversations/sessions/:id`
- 세션 생성:
  - `POST /ai-conversations/sessions`
- 응답 생성:
  - `POST /ai-conversations/respond`
- 음성 STT:
  - `POST /ai-conversations/transcribe`
- 영어 턴 저장:
  - `POST /ai-conversations/turns/:id/save-expression`
- 한국어 턴 저장 후 표현 생성:
  - `POST /ai-conversations/turns/:id/save-sentence/generate-expression`
- 다이얼로그 연습 저장:
  - `POST /ai-conversations/sessions/:id/dialogue-practice`

## 11. 구현 단위 제안

### M1. 진입과 세션 목록
- `Home`에 `AI Conversation` 카드
- `AI Conversation Home` 화면
- 영어 / 한국어 최근 세션 목록
- `영어 대화 시작`, `한국어 대화 시작`

### M2. 텍스트 세션 MVP
- 트랙별 텍스트 세션 생성
- 세션 상세 조회
- 사용자 입력 -> AI 응답
- 최근 세션 이어보기

### M3. 턴 자산화 연결
- 영어 트랙 `영어 표현 생성`
- 한국어 트랙 `저장 후 영어 표현 생성`
- 생성 후 expression 상세 또는 목록으로 자연스럽게 이동

### M4. 음성 대화
- 사용자 STT 입력
- AI 음성 응답
- 영어 트랙 `AI 영문 표시` 옵션

### M5. 세션 자산화 확장
- 영어 트랙 `다이얼로그 연습으로 저장`
- 세션 제목 수정
- 역할 / 상황 / 응답 방식 편집

## 12. 모바일 KPI

### 영어 트랙
- 한 세션 평균 턴 수
- 표현 저장 수
- 다이얼로그 연습 저장 수

### 한국어 트랙
- 수집된 사용자 턴 수
- 턴에서 영어 표현으로 이어진 수
- 이후 `expression practice` / `reviews`로 이어진 수

## 13. 구현 순서 제안
1. `Home`에 `AI Conversation` 진입 카드 추가
2. `AI Conversation Home` 화면 추가
3. 영어/한국어 세션 목록 및 새 대화 시작
4. 텍스트 기반 `Conversation Session`
5. 턴 저장 액션 연결
6. 음성 입력(STT)
7. AI 음성 응답
8. 영어 트랙 `다이얼로그 연습으로 저장`

## 14. 결론
- 영어 트랙은 `연습 중심`
- 한국어 트랙은 `수집 중심`
- UI는 비슷하지만 목적과 저장 액션은 분리
- 모바일에서는 웹처럼 대시보드 복합툴이 아니라 `채팅 중심 + 자산화 액션 최소화` 구조가 맞다
- `Home`에서는 빠른 입구만 제공하고, 실제 대화와 저장은 전용 화면에서 풀어가는 방식이 가장 안정적이다
