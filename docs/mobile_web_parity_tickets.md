# 모바일 웹 기능 패리티 티켓

## 목적
- 현재 웹에 있는 기능 중 모바일 앱에 아직 완전히 반영되지 않은 항목을 개발 티켓 단위로 쪼갠다.
- 이미 모바일에 들어온 핵심 루프와, 아직 비어 있는 섹션/세부 액션을 구분해 우선순위를 정리한다.
- 특히 `AI 대화`, `연습/복습`, `TTS 라이브러리`, `학습 자산`, `데이터 export`의 웹-모바일 차이를 줄이는 것을 목표로 한다.


## 정리 기준
- 웹에 실제 UI/액션이 있는 기능만 대상으로 삼는다.
- 모바일에 일부 구현된 경우 아래처럼 구분한다.
  - `핵심 흐름은 있음`
  - `세부 액션/통합 화면이 없음`
  - `읽기만 되고 관리 액션이 없음`

## 티켓 목록

### Ticket P1. 모바일 AI 대화 섹션 패리티 마감
- 상태:
  - 완료 (2026-05-06)
- 목표:
  - 웹의 `AI 대화 섹션`에서 제공하는 후속 학습 연결과 세션 관리 감각을 모바일에서도 비슷하게 만든다.
- 현재 상태:
  - 모바일에 `AI Conversation Home`, `Session`, `Setup`은 이미 있다.
  - 하지만 웹처럼 `AI 대화 -> 후속 자산화 -> 세션 재열기`가 한 섹션의 흐름으로 강하게 붙어 있지는 않다.
- 범위:
  - 영어 트랙 `대화 후 이어지는 작업` 카드 보강
  - 한국어 트랙 `수집 후 이어지는 작업` 카드 보강
  - 현재 세션 기준 다음 액션 우선순위 정리
  - 최근 세션/현재 세션/후속 학습 이동을 더 짧게 연결
- 주요 화면:
  - `apps/mobile/app/ai-conversation.tsx`
  - `apps/mobile/app/ai-conversation/[id].tsx`
- 완료 조건:
  - 모바일 AI 대화가 단순 채팅 화면이 아니라 웹처럼 `연습/수집 채널`로 읽힌다.

### Ticket P2. 다이얼로그 연습 전역 라이브러리 + 제목 관리
- 상태:
  - 완료 (2026-05-06)
- 목표:
  - 웹의 `다이얼로그 연습 세트 목록` 수준으로 모바일에서도 모든 세트를 탐색하고 관리할 수 있게 한다.
- 범위:
  - 전역 다이얼로그 연습 세트 목록 화면 추가
  - 세트 검색 / 최근순 정렬
  - 세트별 첫 질문 미리보기
  - 세트 제목 수정
  - 세트에서 바로 연습 시작
- 현재 모바일 차이:
  - 지금은 세션 상세에서 `이 세션에서 만든 연습 세트`만 확인 가능
  - 플레이어 화면에서 제목 수정 기능 없음
- 주요 화면:
  - 신규 `apps/mobile/app/dialogue-practice/index.tsx` 또는 동등한 목록 화면
  - `apps/mobile/app/dialogue-practice/[id].tsx`
  - `apps/mobile/app/ai-conversation/[id].tsx`
- 완료 조건:
  - 특정 세션 안으로 들어가지 않아도 전체 다이얼로그 세트를 다시 찾아 연습할 수 있다.

### Ticket P3. 패턴형 연습 패리티
- 상태:
  - 완료 (2026-05-06)
- 목표:
  - 웹의 `패턴형` 문제 유형과 결과 화면을 모바일 연습/복습에 동일하게 반영한다.
- 범위:
  - 표현 연습에 `패턴형` 문제 유형 노출
  - 복습 탭에 `패턴형` 문제 유형 노출
  - 패턴 설명 / 기준 표현 / 원래 대표 표현 표시
  - 패턴형 결과 피드백 구조 정리
- 현재 모바일 차이:
  - 타입은 준비되어 있지만 선택 UI는 `translation / situation / think`만 노출됨
- 주요 화면:
  - `apps/mobile/app/expression/[id]/practice.tsx`
  - `apps/mobile/app/(tabs)/reviews.tsx`
- 완료 조건:
  - 모바일에서도 패턴형 문제를 생성하고 푸는 기본 흐름이 웹과 같아진다.
